# পলাশী (Polashi) — ঐতিহাসিক সামাজিক ডিডাকশন বোর্ড গেম

১৭৫৭ সালের ঐতিহাসিক **পলাশীর যুদ্ধ** এবং প্রাসাদ ষড়যন্ত্রের পটভূমিতে নির্মিত অনলাইন সামাজিক ডিডাকশন বোর্ড গেম।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **রুম তৈরি ও যোগদান (Room Code System):**
   - যেকোনো খেলোয়াড় ৫-অক্ষরের কোড (যেমন: `PLS24`) দিয়ে রুম তৈরি করতে পারেন।
   - অন্য বন্ধুরা কোড ব্যবহার করে যেকোনো ব্রাউজার থেকে খেলায় যোগ দিতে পারেন।
2. **খেলোয়াড় সংখ্যা ও ব্যালেন্স (৫ থেকে ১০ জন):**
   - ৫ থেকে ১০ জনের জন্য নিয়ম অনুযায়ী নবাব ও কোম্পানি পক্ষের স্বয়ংক্রিয় বণ্টন।
3. **খেলার মোড (Game Modes):**
   - **স্বাভাবিক মোড (Basic Mode):** শুধুমাত্র মীর মদন ও মীর জাফর বিশেষ চরিত্রে।
   - **অতিরিক্ত চরিত্র মোড (Extra Mode):** মোহন লাল, রায় দুর্লভ, উমিচাঁদ ও ঘষেটি বেগম সহ।
4. **কাস্টমাইজযোগ্য টাইমার (Customizable Timers):**
   - দল মনোনয়ন আলোচনা টাইমার (ডিফল্ট ৩ মিনিট)।
   - ভোটাভুটি আলোচনা টাইমার (ডিফল্ট ১ মিনিট)।
   - মীর জাফরের হত্যা আলোচনা টাইমার (ডিফল্ট ৫ মিনিট)।
   - টাইমার বন্ধ রাখার অপশন (সবার সাবমিশন আসা পর্যন্ত অপেক্ষা)।
5. **১০০% ফ্রি ও সার্ভারলেস রিয়েল-টাইম আর্কিটেকচার (WebRTC DataChannels):**
   - ব্রাউজার-টু-ব্রাউজার পিয়ারলেস কানেকশন (PeerJS)।
   - কোনো অতিরিক্ত সার্ভার বা ডাটাবেস খরচের প্রয়োজন নেই। Vercel-এ সরাসরি ডেপ্লয়যোগ্য।
6. **একই ডিভাইসে খেলা (Hotseat / Pass & Play):**
   - বন্ধুদের সাথে একই ফোন বা ট্যাবলেটে খেলার জন্য লোকাল মোড।
7. **ভয়েস চ্যাট গাইডলাইন:**
   - গেমটি ব্যাকগ্রাউন্ডে Discord বা Google Meet / Messenger কল রেখে সবচেয়ে সাবলীলভাবে খেলা যায়।

## 🚀 লোকাল সেটআপ ও রান (Local Run)

```bash
# ডিপেন্ডেন্সি ইনস্টল (যদি ইতিমধ্যে না থাকে)
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev
```

ব্রাউজারে ওপেন করুন: `http://localhost:3000`

## 🌐 Vercel-এ ডেপ্লয় করার নিয়ম (Deploy to Vercel)

1. আপনার গিট রিপোজিটরিতে কোড পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Palashi game"
   # আপনার GitHub/GitLab রিপোতে পুশ করুন
   ```
2. [Vercel](https://vercel.com)-এ গিয়ে **Add New Project** সিলেক্ট করুন এবং রিপোজিটরি ইমপোর্ট করুন।
3. কোনো অতিরিক্ত Environment Variables এর প্রয়োজন নেই! সরাসরি **Deploy** বাটনে ক্লিক করুন।
